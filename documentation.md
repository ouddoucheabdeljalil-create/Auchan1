1. fetch()
=>  La méthode fetch() est une API native du navigateur JavaScript Fetch qui permet d'envoyer des requêtes HTTP (comme GET, POST, PUT, DELETE) pour récupérer ou envoyer des données à un serveur .
2. local Storage : 
=> c'est un mécanisme de stockage web intégré aux navigateurs internet qui permet aux sites web de conserver des données directement sur l'appareil de l'utilisateur .
3. module ES6 :
=> c'est un fichier JavaScript contenant du code réutilisable que l'on peut séparer et partager entre différents fichiers d'un projet.
4. find()
=> La méthode permet de rechercher et de retourner le premier élément d'un tableau qui satisfait une condition. Si aucun élément ne correspond, elle retourne undefined.
5. filter()
=> La méthode permet de créer un nouveau tableau contenant tous les éléments qui satisfont une condition. Si aucun élément ne correspond, elle retourne un tableau vide.
6. JSON
=> c'est un format léger d'échange de données qui permet de stocker et de transmettre des informations sous forme de texte structuré, en utilisant des objets et des tableaux. Il est indépendant du langage de programmation.
7. callback :
=>Une callback est une fonction passée en argument à une autre fonction, afin d'être exécutée ultérieurement, après une opération ou lorsqu'un événement se produit.
8. setTimeout()
=> La méthode permet d'exécuter une fonction après un délai déterminé, exprimé en millisecondes .
9. Try :
=> Permet d'exécuter un bloc de code susceptible de provoquer une erreur.
10. catch :
=> Permet de capturer et de gérer les erreurs qui se produisent dans le bloc try.
11. finally : 
=> Permet d'exécuter un bloc de code dans tous les cas, qu'une erreur se produise ou non.
