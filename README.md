🛒 AUCHAN – Plateforme E-commerce

📌 Présentation du projet

AUCHAN est une application web e-commerce qui permet aux clients de consulter un catalogue de produits, rechercher des articles et gérer leur panier. Elle propose également un espace administrateur pour gérer les produits.

🚀 Technologies utilisées

.HTML5

.Tailwind CSS

.JavaScript ES6+

.JSON

.LocalStorage

.Fetch API

.Git & GitHub

👤 Interface Client

Afficher le catalogue des produits.

Rechercher et filtrer les produits.

Naviguer entre les pages avec la pagination.

Afficher les produits en mode Grid ou List.

Ajouter des produits au panier avec Drag & Drop.

Modifier les quantités et supprimer des articles.

Calculer automatiquement le total du panier.

⚙️ Interface Administrateur

Ajouter un nouveau produit.

Afficher la liste des produits.

Modifier les informations d'un produit.

Supprimer un produit.

Mettre à jour les données dans LocalStorage.

📞 Page Contact

Formulaire avec validation Regex.

Générer des données de test avec l'API RandomUser.
